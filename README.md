# Biolab Landing Page

## Descrição do Projeto

Esse projeto consiste no desenvolvimento de uma **landing page institucional** para a Biolab Farmacêutica, com o objetivo de modernizar sua presença digital.
A página foi feita com base no padrão de componentes do Relume Figma Kit, seguindo as práticas de estruturação, responsividade e organização do código.

---

## Objetivo
Criar uma landing page completa contendo:

- Seção Hero (Header)
- Seção de Diferenciais (Features)
- Seção de Depoimentos (Testimonials)
- Seção de Contato (CTA)
  
---

## Tecnologias Utilizadas

- HTML5
- CSS3
- Google Fonts
- GitHub

---

## Estrutura de Pastas

### Recursos Utilizados

- Tipografia importada via Google Fonts
- Uso de variáveis CSS (`:root`)
- Layout responsivo com breakpoint para dispositivos móveis (`max-width: 768px`)
- Organização baseada em componentes
